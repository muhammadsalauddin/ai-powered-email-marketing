# Crownvo.com Growth OS Presentation

This workspace contains a static documentation-style presentation for Crownvo.com, the email marketing platform built on its own proprietary script foundation, and the planned AI operator layer.

Files:

- `index.html` - Main presentation page
- `styles.css` - Visual design and layout
- `app.js` - Mermaid initialization and sidebar section tracking

How to use:

1. Open `index.html` directly in a browser, or serve the folder with a simple local server.
2. The diagrams render with Mermaid from a CDN, so an internet connection is required for graph rendering.

Suggested local preview command:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.
